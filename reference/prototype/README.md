# مرجع التصميم المعتمد

هذا النموذج للمقارنة البصرية والسلوكية فقط. كود الحسابات والتخزين والتقييم والنشر فيه محاكاة، ولا يمثل خدمات إنتاج. أبقِه مستقلًا عن تطبيق الإنتاج.

من هذا المجلد: `npm ci` ثم `npm run dev`. للاختبارات: `npm test`، وللمتصفح بعد `npx playwright install chromium`: `npm run test:e2e`. صور المقارنة مرجعية لـWindows.

النظام البصري Professional blue مع تفضيلات شخصية، والعربية/الإنجليزية، ومدخل academy.html. المتطلبات والعقود في ../../docs، والأصول المولدة الأصلية والمحسنة في public/assets. راجع THIRD_PARTY_NOTICES.md قبل إعادة استخدام الاعتماديات.
