# SpecialSite — ملفات بدء المشروع الإنتاجي

هذا هو المجلد الوحيد المطلوب نقله إلى مكان المشروع الجديد. افتح `specialsite.code-workspace` في VS Code، ثم أرسل إلى Codex:

> اقرأ AGENTS.md وdocs/handoff/START.ar.md وابدأ المرحلة 00 للمشروع الجديد وفق التعليمات.

## المحتويات المختارة

| المسار | لماذا نحتاجه؟ |
|---|---|
| `AGENTS.md` و`CLAUDE.md` | أدوار التطوير والمراجعة وقواعد الجودة |
| `docs/01..05` و`docs/07..09` | التصميم، الصفحات والحالات، تصور البيانات، الاختبارات، المناهج والصور والتفضيلات |
| `docs/standards/` | معايير React و.NET الخاصة بالمشروع |
| `docs/governance/` | المراحل المتسلسلة وآلية المراجعة وقالب التقرير |
| `docs/handoff/` | تعليمات البدء والتبادل بين الإضافتين وGitHub |
| `docs/phases/` | سجل تنفيذ جديد ونطاق المرحلة الأولى، دون نتائج أو موافقات سابقة |
| `reference/prototype/` | مصدر التصميم المعتمد القابل للتشغيل، اختبارات السلوك والصور المرجعية، الأصول الأصلية والمحسنة وتراخيص الاعتماديات |
| `scripts/governance/` | أدوات تحضير واستيراد مراجعة الإضافة، التحقق من الأدلة، الاختبارات والفحوص |
| `.vscode/` و`specialsite.code-workspace` | مهام التشغيل والاختبار وفتح المجلد في VS Code |

لا يوجد Backend إنتاجي بعد. `reference/prototype` مرجع مستقل؛ تسجيل الدخول والتقييم والنشر فيه محاكاة يجب استبدالها بخدمات حقيقية في التطبيق الإنتاجي. يحدد Codex تنظيم ملفات الإنتاج في مرحلة العقود، ويحافظ على المرجع للمقارنة.

استُبعدت سجلات المحاولات والمراجعات القديمة، تاريخ `.git`، الصور التوثيقية الزائدة، تقارير التشغيل، `node_modules` و`dist`، ملفات ZIP، وتعليمات الرفع القديمة المرتبطة بتاريخ سابق. الحزم الأصلية محفوظة خارج هذا المجلد. بقيت الاختبارات وصور المقارنة والأصول الأصلية لأنها تساعد في منع تراجع التصميم والوظائف.

لم تُنقل موافقات قديمة أو نتائج نجاح إلى السجل الجديد؛ لم تكن هناك مراجعة Claude مكتملة. جميع المراحل تبدأ `planned`، ولا يعني ذلك إعادة ضبط جولات مراجعة مكتملة. المستودع المستهدف يبقى `nextleapgit/specialsite`، مع فحص تاريخه قبل أي رفع من VS Code.

## تشغيل المرجع

من جذر المجلد: `npm run reference:install` ثم `npm run reference:dev`. تحتاج اختبارات المتصفح تثبيت Chromium من مهمة VS Code المخصصة. البيئة المرجعية Windows وNode.js 24.12.0؛ الإصدارات هنا خاصة بالنموذج، ويُتحقق من إصدارات الإنتاج في المرحلة 01.

الأوامر `lint` و`typecheck` و`test` و`build` و`test:e2e` الحالية تخص المرجع. `test:governance` يختبر أدوات المراجعة. قبل مراحل الإنتاج يضيف Codex فحوص التطبيق الجديد الفعلية؛ فحوص النموذج وحدها لا تثبت جاهزيته. لا يحتاج جذر المجلد تثبيت حزم؛ الاعتماديات المقفلة داخل `reference/prototype`.
