# بيئة اختبار المرجع دون تعديل الأصل

يبقى reference/prototype كاملًا دون تغيير، بما فيه الاختبارات والصور والإصدارات. يشغّل npm run test:e2e الحاضنة scripts/governance/reference-e2e.mjs التي تستعمل Playwright المثبت في المرجع، وتحافظ على مجلد العمل والخادم ومخرجات التشخيص. لا تثبيت أو اعتماديات جديدة.

كشفت محاولتان محفوظتان في docs/phases/00/attempts/public-quality-01 وpublic-quality-02 أن قياس التباين يمكن أن يحدث أثناء انتقال الخلفية الذي مدته 0.15 ثانية، بين لونين نهائيين. اختلفت العناصر واللوحات في الإخفاقين، وكانت الألوان المسجلة وسيطة (#8957f2 و#787c86). لا تُعلن المحاولتان ناجحتين ولا تُحذفان.

تشغّل الحاضنة الاختبارات الأصلية الثلاثين بوضع prefers-reduced-motion=reduce المدعوم أصلًا في CSS المرجع. لا تغير الصور المرجعية أو حد فروق الصور أو assertions أو قواعد axe. وتضيف اختبارين في وضع no-preference العادي: كل اللوحات الخمس بنمطي الإضاءة في التفضيلات، ومعاينات المظهر الثلاث بنمطيها. تنتظر الاختبارات الإضافية اكتمال document.getAnimations().finished وإطار الرسم قبل فحص WCAG نفسه، دون حقن CSS أو إسكات مخالفة.

بهذا يُقاس التباين في الحالة المرئية المستقرة في كلا الوضعين بدل أخذ عينات أثناء الانتقال. لا تثبت هذه الفحوص تباين كل إطار أثناء الحركة، ولا تُنسب إليها تغطية لذلك. تعالج واجهة الإنتاج الحركة والوصول ضمن مرحلتها؛ المرجع ليس تطبيق إنتاج. يعتمد الفحص النهائي على نجاح كل الحالات الـ32 فعلًا دون retries أو skips، ويستخدم GitHub الأمر نفسه.

واجهة Playwright المستخدمة: https://playwright.dev/docs/api/class-testoptions#test-options-reduced-motion
