# عقد المراحل والجودة

هذا سجل مشروع إنتاجي جديد. التصميم معتمد، لكن لا مرحلة تنفيذ معتمدة ولا مراجعة Claude مكتملة. تبدأ المرحلة 00 بتأسيس المستودع وCI والحماية وآلية الأدلة، ثم المرحلة 01 للعقود والبيانات قبل تنفيذ الخدمات. راجع phases.md، وdocs/handoff/IDE-WORKFLOW.ar.md للأوامر.

الحالات: planned → implementing → reviewing/remediating → ready → merged_verifying → complete، مع blocked عند العائق. لا تبدأ المرحلة التالية حتى اكتمال السابقة ودمجها ونجاح الاختبارات على النتيجة.

في كل جولة: تقرير Codex، المصدر/الفروق، اختبارات كاملة للنطاق والوظائف السابقة، تقرير أمني، ثم مراجعة Claude مستقلة. Codex يصلح مع اختبار يمنع رجوع كل عيب، وClaude يتحقق من الإغلاق والأثر الجانبي. أربع جولات مكتملة كحد أقصى؛ العيوب الصحيحة المفتوحة تمنع الاعتماد بكل مستويات الشدة، ولا يبرر الحد إعفاءها.

يحوي docs/phases/NN/round-XX: codex.md، remediation.md، security.md، tests.json وlogs، request.json، claude-input.txt، رد Claude الأصلي claude-extension.json، والنتيجة المستوردة claude.json، مع تقريره التفسيري اختياريًا. تحفظ الأدلة بعد التسليم دون إعادة كتابة؛ المحاولات الفنية تحفظ في attempts. أي تغير مصدر أو اختبار أو سياسة يبطل المراجعة السابقة.

تطبق unit/component/integration/E2E/accessibility/visual/performance/security حسب docs/05-test-strategy.md. مرحلة الإنتاج تختبر PostgreSQL فعليًا والصلاحيات والجلسات وCSRF؛ مشغل C# يخضع لاختبارات عزل وحدود الموارد والشبكة والملفات وتزوير الدرجة. تشمل التكاملات التكرار وidempotency والإلغاء والرموز وwebhooks، وتشمل AI الحقن والموافقة والإصدارات وحدود الاستهلاك.

فحص أمني نهائي في نهاية كل مرحلة على السطح الذي بُني، ثم فحص شامل قبل الإطلاق: dependency/secret/SAST/container/IaC حيث تنطبق، وDAST معزول واختبارات هجومية للمشغل ونسخ احتياطي واستعادة وrollback وتحميل. لا اختبار هجومي لخدمات خارجية أو الإنتاج بلا تصريح. الفحص الفاشل أو غير المنفذ لا يُسمى نجاحًا؛ لا ضمان بغياب جميع الثغرات المجهولة.

الفحص المحلي يتحقق من اتساق الأدلة، وليس شهادة مستقلة لهوية Claude أو حماية GitHub. آخر SHA وفحوص CI والحماية وPR ونتيجة الدمج تُتحقق فعليًا. التقارير الذاتية ليست بديلًا لهذا الإثبات. تُنفّذ آلية إغلاق المرحلة بعد الدمج دون دورة اعتماد مستحيلة ضمن المرحلة 00.

لا موافقات روتينية على التطوير والإصلاح والاختبارات والفروع والدمج المستوفي للشروط. تدخل المستخدم للصلاحيات غير المتاحة، التكلفة الجديدة، تعارض نطاق جوهري، أثر إنتاجي غير قابل للتراجع، أو عيوب بعد الجولة الرابعة. تبقى الأسرار خارج المصدر والتقارير والنماذج.
