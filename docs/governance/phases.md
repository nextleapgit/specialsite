# سجل المراحل المعتمد

هذا الترتيب يحل محل ترقيم المراحل السابق. لا تبدأ مرحلة قبل اكتمال جميع شروط سابقتها. التنفيذ داخل المرحلة قد يشمل مهام صغيرة، لكن لا يغيّر حدود القبول لتجاوز المراجعة.

| المرحلة | النطاق | شرط خروج إضافي إلى بوابة الجودة العامة |
|---|---|---|
| 00 — Governance | حفظ التصميم، المستودع، نظام التقارير والمراجعات والبوابة | مراجعة Claude فعلية، فحوص محلية، مستودع عام بقرار المستخدم مع حماية وCI وPR ودمج موثق |
| 01 — Contracts | جرد UI، architecture/ADRs، ERD، ملكية البيانات، OpenAPI، threat model، بيئة تشغيل واختبار | كل حالة UI تقابل عقدًا؛ سياسات الجلسات والإتقان والاحتفاظ/الحذف والنسخ والإرسال محسومة؛ عقود مراجعة وأمن قابلة للاختبار |
| 02 — Identity & Preferences | ASP.NET Core + PostgreSQL، حسابات وصلاحيات، تحقق البريد والاستعادة، تفضيلات حقيقية | تدفق register→verify→login→preferences→logout/login؛ اختبارات PostgreSQL وصلاحيات وCSRF واستعادة؛ فصل وضع العرض من الإنتاج |
| 03 — Content | المقالات والتصنيفات والمشاريع والمحرر والمراجعات والوسائط، عرض عام سريع وSEO | منع تسريب المسودات؛ sanitization، تعارض تعديل، ملكية وصلاحيات، SEO/cache؛ تطابق التصميم |
| 04 — Training Records | لغات/مناهج بإصدارات، أقسام ودروس، تسجيل، جلسات ومحاولات ودرجات وتقدم | عزل المستخدمين، سجلات تاريخية قابلة للتفسير، ترقية المنهج، إعادة المحاولة؛ لا نسب تشغيل C# حقيقية إلى fixture |
| 05 — C# Runner | محرر فعلي، خدمة تشغيل معزولة، اختبارات مخفية وتقييم | عزل هجومي مثبت، حدود موارد، منع الشبكة/الأسرار، ملكية المهام، درجة من الخادم، فشل/مهلة وإلغاء وتعافٍ |
| 06 — AI Curriculum | توليد/تعديل مقترح، diff، مراجعة واعتماد، إصدارات | لا نشر تلقائي، موافقة صاحب الصلاحية، عدم فقد المحاولات، حدود تكلفة وprompt injection وعقود مزود وأعطال |
| 07 — Delivery | نشر موقع + بريد + LinkedIn افتراضي، اشتراكات وتفضيلات وربط حسابات | OAuth وإلغاء، تشفير رموز، outbox/retry/idempotency، unsubscribe، توقيع webhooks، حالات نجاح جزئي ومطابقة سياسة الموافقة |
| 08 — Release | الدمج النهائي، تشغيل ومراقبة ونسخ وrollback ونشر | كامل matrix الأمن/الأداء/الوصول/المتصفحات، restore drill، لا mocks إنتاجية، أسرار صحيحة، دليل تشغيل وفحوص staging |

قبل تنفيذ أي مرحلة، ينشئ Codex `scope.md` بقائمة acceptance IDs ونطاق الملفات وrequired checks. مراجعة Claude تقيس التنفيذ مقابل هذه القائمة. بوابة مرحلة 00 لا تعتمد تلقائيًا نجاح مراحل الخادم أو التدريب أو الإطلاق.

قرارات التكنولوجيا الأساسية: React/TypeScript للواجهة، ASP.NET Core بهيكل وحدات ضمن تطبيق واحد، PostgreSQL، ASP.NET Identity وجلسات cookies آمنة، عامل خلفي/outbox، وتشغيل C# خارج عملية الـAPI. تثبيت إصدارات مدعومة بعد التحقق الرسمي في المرحلة 01؛ لا شراء خدمات تلقائيًا.
