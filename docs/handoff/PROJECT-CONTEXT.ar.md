# المتطلبات والقرارات المعتمدة

منصة Abdulnaser Ramadan شخصية للمحتوى والتدريب. التصميم المعتمد Professional blue افتراضيًا، مع تفضيلات المستخدم للألوان والخطوط وحجم القراءة وlight/dark/system، ودعم العربية/RTL والإنجليزية. الأولوية للسرعة والبساطة والاستجابة والوصول.

المحتوى: Articles بتصنيفات Digital Transformation وSoftware Architecture و.NET وBusiness & Operations؛ Projects؛ Newsletter؛ Training. الصفحات المطلوبة تشمل الرئيسية والمقالات والتفاصيل والمشاريع والاشتراك والتدريب وفهرس الدورة والدرس والتسجيل/الدخول ولوحة المستخدم والتقدم والحسابات المرتبطة والإدارة ومحرر المقال والنشر وإدارة المناهج.

التدريب في مدخل مستقل. يبدأ C# بـ30 درسًا و10 أقسام مرجعية، مع إمكانية إضافة لغات ودورات لاحقًا. التسجيل إلزامي؛ شرح وفهرس ومحرر مع إكمال اختياري وتشغيل وتقييم وإعادة ضبط، مخرجات ودرجة وفحوص مخفية وتاريخ جلسات ومحاولات وإتقان وإعادة تدريب. درجات حقيقية من خدمة معزولة، وسجلات محفوظة لكل مستخدم ومحاولة وإصدار درس؛ لا تثق بدرجات العميل.

إعداد المحتوى يوفر اقتراح منهج جديد أو تعديل القائم بالذكاء الاصطناعي، مع معاينة ومراجعة واعتماد صريح وإصدارات؛ لا نشر تلقائي لناتج غير معتمد. ربط التواصل يفضل LinkedIn افتراضيًا. نشر المقال يدعم الموقع والبريد وLinkedIn، حالات نجاح جزئي وإعادة محاولات لا تكرر التسليم الناجح. الاشتراك بالبريد يتضمن الموافقة والتفضيلات والإلغاء والإرسال للمشتركين المستحقين عند نشر المقال.

النموذج في reference/prototype يحتوي المحاكاة المرئية فقط: لا حسابات أو قاعدة بيانات أو تشغيل C# أو إرسال بريد/LinkedIn أو LLM فعلي. يُستفاد من تصميمه وسلوكه وأصوله واختباراته، ثم تُبنى الوظائف الحقيقية بعقود واضحة. الصور واللوغو مولدة خصيصًا؛ الأصول الأصلية والنسخ المحسنة موجودة، دون صور ويب أو خطوط موزعة من مصادر خارجية.

الاتجاه المعماري: React/TypeScript، ASP.NET Core كتطبيق مقسم إلى وحدات، PostgreSQL، Identity مع cookies آمنة وCSRF، OpenAPI مشترك، outbox وعامل مهام، ومشغّل C# معزول عن API. الإصدارات وسياسات البيانات والإتقان والاحتفاظ تُراجع في المرحلة 01. معايير المستخدم الكاملة في docs/standards. docs/04 اقتراح تصميم وليس مخطط قاعدة بيانات معتمدًا.

ترتيب المراحل الوحيد المعتمد في docs/governance/phases.md. لا تعتمد أرقام مراحل أقدم في الوثائق المرجعية أو مجرد نجاح اختبارات النموذج لإثبات جاهزية الإنتاج. كل مرحلة تنتج تقارير واختبارات ومراجعات مستقلة؛ لا انتقال قبل الاعتماد والدمج والتحقق.
