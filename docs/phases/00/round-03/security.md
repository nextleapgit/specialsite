# المرحلة 00 / الجولة 03 / الفحص الأمني

التغيير في مسار طلب REST فقط: حذف الشرطة المائلة النهائية من endpoint المستودع عندما يكون path فارغًا، مع حفظ المسارات الفرعية وpagination. لا تغيير للحماية أو المصادقة أو الرؤية العامة التي اختارها المستخدم. لا أسرار في الوسائط؛ gh يستخدم المصادقة القائمة، وتبقى المخرجات stdio pipe وأداة التنفيذ الافتراضية execFileSync دون shell.

معامل execute الاختياري موجود لتسجيل الوسائط في اختبار معزول دون اتصال خارجي؛ الاستدعاءات التشغيلية تستخدم القيمة الافتراضية. الاختبار يفحص الجذر والمسار الفرعي وquery وpagination، وأثبت الاختبار المحدد نجاح 37 حالة إغلاق بما فيها رفض تجاوز الإدارة وforce push والحذف والمصدر المتغير والدمج غير المثبت والفحوص الفاشلة.

المستودع عام بقرار المستخدم، وحماية main وفحوص GitHub Actions المطلوبة ما زالت مفعلة. لم يحدث دمج عند خطأ 404 ولم تُزال الحماية لتجاوزه. كل أدلة الجولتين السابقتين ثابتة؛ لا تعديل لحكم Claude أو إعادة تسمية جولة مكتملة. عدد الجولات المكتملة قبل الإرسال اثنتان، وهذه الثالثة ضمن الحد الأقصى أربع.

تُعاد الفحوص التسعة بما فيها تدقيق الاعتماديات وفحص أنماط الأسرار؛ نتائج هذه الجولة وحدها هي الدليل الحالي. فاحص الأسرار محدود بالأنماط المعروفة والملفات الحالية، وليس ضمانًا شاملًا أو فحصًا للتاريخ. لا سطح إنتاج جديد أو قاعدة بيانات أو تنفيذ للمرحلة 01 ضمن هذا التغيير.
