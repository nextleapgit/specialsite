# المرحلة 00 / الجولة 02 / الفحص الأمني لتصحيح الترميز

التغيير في المصدر محصور بوصف مهمة VS Code؛ لا أدوات أو اعتماديات أو صلاحيات أو اتصالات جديدة. أصل المشكلة هو تمرير Unicode عبر قناة بترميز غير مناسب. كُتبت تقارير التصحيح باستخدام UTF-8 صريح دون BOM، ويُتحقق من محتواها بعد الكتابة بدل افتراض سلامة العرض في الطرفية.

هذا تصحيح مستقل للفقرة التالفة في تقرير أمان الجولة الأولى: نجح فحصا dependency-audit وsecret-scan برمز 0 في تلك الجولة، ولم يبلغا عن ثغرات اعتماديات أو أسرار تطابق الأنماط المفحوصة. تُحفظ النتائج الأصلية في سجلات الجولة الأولى. لا يعني ذلك خلو المشروع من جميع الثغرات، ولا يشمل فاحص الأسرار التاريخ أو جميع أنماط الأسرار الممكنة. لا يُنسب نجاح الجولة الأولى تلقائيًا إلى المصدر المعدل؛ تعاد الفحوص وتُحفظ نتائجها في هذه الجولة.

ورد الإذن الصريح من المستخدم بإرسال المصدر الخاص وأدلة الاختبارات إلى Claude وتسليم النتائج إلى Codex. نُفذ الإرسال بعد الإذن، وسُجل الرد الأصلي مع معرّف الجلسة وبصمات المصدر والطلب والمدخل والرد. لا مفاتيح أو رموز دخول في رسائل التسليم، ولم تتغير خصوصية المستودع أو الخطة أو صلاحيات الحماية. يحتفظ المستخدم بتأكيد الرفع عند الجاهزية.

تظل جميع أدلة الجولة الأولى ثابتة حتى عندما تحتوي العيب المبلغ عنه. تُعالج GOV-00-EVID-01 بتصحيح جديد واضح مع حفظ الأصل، وليس بتغيير الرد أو الأدلة التي قرأها المراجع. لم يمنح Claude اعتمادًا للمرحلة. العائق المسجل لحماية GitHub وغياب CI والدمج البعيد لا يزال قائمًا، ولذلك لا دمج ولا انتقال للمرحلة التالية.
