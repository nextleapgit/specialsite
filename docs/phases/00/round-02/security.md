# المرحلة 00 / الجولة 02 / الفحص الأمني

السطح هو الحوكمة وأدوات المراجعة، دون خدمة إنتاج جديدة أو اعتماديات إضافية. تغيير المستودع إلى عام نفذه المستخدم صراحة، وتم التحقق من حالته عبر GitHub. لم تُرفع أسرار أو تتغير إعدادات شراء؛ فاحص أنماط الأسرار ضمن الفحوص الكاملة محدود بالملفات الحالية والأنماط المعروفة ولا يضمن خلو التاريخ من كل نوع سر.

حماية main مطبقة على الإدارة والفحوص الثلاثة المرتبطة بتطبيق GitHub Actions، وتفرض تحديث الفرع وحل المحادثات وتمنع force push والحذف وbypass. لا موافقة GitHub مصطنعة: required_approving_review_count=0، والمراجعة المستقلة الفعلية لـClaude مفروضة عبر phase-evidence. لا إزالة للحماية لتسهيل الدمج.

استئناف blocked إجراء صريح بعد توثيق حل العائق؛ لا يغير النتيجة السابقة أو عدد الجولات، ولا يمنح اعتمادًا، ولا يستمر عبر blocked جديد أو الجولة الرابعة. أضيف اختبار رجوع لهذه الحالات. تعديل شرط الرؤية في محقق الإغلاق محدد للمستودع العام الذي اعتمده المستخدم، وليس قبولًا لأي مستودع أو حذفًا للتحقق من الهوية.

تظل مراجعة Claude read-only والرد الخام ومعرّف الجلسة محفوظين، وتتوقف كتابة المصدر أثناء المراجعة. اختلاف المصدر يبطل أي اعتماد سابق. لا تُعدل الأدلة المرسلة لإخفاء عيب الترميز؛ التصحيح في التقارير الجديدة فقط. التصحيح المقروء لخاتمة أمان الجولة الأولى: اجتاز تدقيق الاعتماديات وفحص الأسرار هناك برمز 0، ولم يبلغا عن نتائج مخالفة ضمن نطاقهما؛ دليل الجولة الجديدة مستقل في logs الحالية.

نجاح مراجعة المصدر لا يثبت نجاح CI الذي يستهلك نتيجتها ولا الدمج؛ يجب التحقق من هذه الوقائع لاحقًا قبل الانتقال. هذا يمنع اعتمادًا دائريًا دون السماح بتجاوز فحص. يظل تقرير الأمن محدودًا بالسطح المبني، دون ادعاء فحوص إنتاج غير موجود.
