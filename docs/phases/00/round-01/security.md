# المرحلة 00 / الجولة 01 / الفحص الأمني للمنسّق

السطح هو أداة التنسيق المحلية والحوكمة والمرجع، دون خدمة إنتاج أو قاعدة بيانات. لم تُضف اعتماديات أو تُحدّث حزم المرجع. تُستخدم وحدات Node المدمجة وأدوات مثبتة بالفعل؛ فحص المصادقة طبع النوع فقط ولم تُنسخ بيانات الحساب أو الرموز إلى التقارير.

أداة Claude مقيدة بالقراءة والبحث داخل مجلد العمل، وتُعطّل تخصيصات hooks/skills وMCP في جلستها الآلية. أداة Codex تبقى ضمن workspace-write وبسياسة رفض طلبات الرفع غير التفاعلية؛ لا bypass ولا danger-full-access. النص يُرسل في stdin، والمسارات والوسائط منفصلة عن shell. تُتحقق خيارات CLI قبل الاستدعاء كي لا تُحذف خيارات الأمان لمعالجة نسخة أقدم. متغيرات مزودي API أو مفاتيحهم تمنع بدء التنسيق تلقائيًا بدل تحويل الفوترة إلى مسار جديد.

قفل مملوك لعملية واحدة يمنع منسّقًا ثانيًا. تُجمّد بصمة المصدر وملفات الجولة والحالة أثناء المراجعة، وتُحفظ نتيجة Claude الخام دون إعادة صياغة. تُطابق البوابة request/input/raw hashes ومعرّف الجلسة والمخرجات المستوردة. تغيير المراجع أو الأدلة أو المصدر يرفض الاستيراد/الاعتماد. اختبارات الرجوع تشمل فشل العملية والمهلة والرد المشوه والاستئناف وعدم استدعاء المراجع مجددًا عند وجود نتيجة صحيحة.

تدقيق الاعتماديات وفحص أنماط الأسرار ضمن quality، ونتيجتهما الأصلية في logs. فاحص الأسرار محدود بالأنماط المعروفة والملفات الحالية ولا يفحص التاريخ أو entropy. ليست هناك شهادة بخلو كل ثغرة، ولا فحص DAST أو container/IaC لسطح إنتاج غير مبني.

الحدود: القفل ينسق العمليات التابعة للأداة ولا يمنع مستخدمًا أو إضافة أخرى من تحرير الملفات، لذلك تُمنع الكتابة المتزامنة إجرائيًا ويُرفض تغيير البصمة. الأدلة المحلية ليست تصديق مزود تشفيريًا. لا حماية GitHub مثبتة ولا إذن دمج من نجاح الاختبارات؛ العائق السابق ما زال مانعًا. المهلة تغلق شجرة العملية على Windows، وعلى غيره تُنهى العملية المباشرة. يظل تشغيل الجودة وتنفيذ مهام التطوير ضمن تفويض المشروع المعتاد، ولا يُسمح للمنسّق بتغيير خصوصية المستودع أو تكاليفه أو دفع/دمج العمل.
