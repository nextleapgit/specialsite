# المرحلة 00 / الجولة 01 / تقرير Codex — المنسّق

الفرع phase/00-governance. طلب المستخدم إضافة منسّق للتسليم والاستلام، وأكد أنه لم يشغّل حزمة مراجعة الإضافة السابقة. نُقلت تلك الحزمة كاملة إلى attempts/pre-coordinator-01 مع قائمة hashes جرى التحقق منها قبل النقل وبعده. لم تُستورد مراجعة سابقة ولم يُصفّر عدّاد جولات مكتملة. هذه الحزمة الجديدة تستخدم channel=cli، وتحمل request.json بصمة المصدر وcommit التنفيذ الفعلي.

## التغيير ومعرّفات القبول

GOV-00-09: أضيف coordinator.mjs مع قفل حصري، حالة وسجل أحداث، دورة متسلسلة للفحوص ثم Claude ثم استيراد الرد ثم Codex عند changes_requested. يتوقف عند blocked أو فشل أو حد أربع جولات، ولا يدفع أو يدمج أو يبدأ مرحلة تالية. الاستئناف يعيد استعمال الرد الصحيح الموجود، ويصالح الاستيراد مع عدّاد الحالة دون استدعاء مكرر. إذا تغير كود أدوات الحوكمة أثناء إصلاح ذاتي، يتوقف قبل تنفيذ النسخة المعدلة.

coordinator-process.mjs يستخدم native executables بوسائط مستقلة وstdin؛ لا يُفسّر prompt كأمر shell. يفحص المصادقة القائمة وميزات النسخة، ويمنع متغيرات API/provider المختلفة. Claude يعمل بRead/Glob/Grep وsafe-mode/restricted دون Bash أو كتابة أو MCP أو تخصيصات المستخدم؛ Codex يعمل workspace-write دون رفع تلقائي للصلاحيات. لا تعديل لإعدادات الحساب الدائمة ولا تثبيت اعتماديات جديدة.

cli-review.mjs يحضر طلبًا مرتبطًا بالمصدر والفروق والتقارير والسجلات، ويستورد نتيجة Claude الأصلية structured_output مع session_id الحقيقي وبصمات request/raw/input. بوابة gate تتحقق من هذا الإثبات بالإضافة إلى قواعدها السابقة. أُخرجت قوائم الفحوص إلى required-checks.mjs ليشترك المحضّر والبوابة في الشروط نفسها. بقي مسار الإضافة اليدوي متاحًا، مع تمييز النقلين صراحة في AGENTS.md وCLAUDE.md ودليل التسليم. أضيفت ثلاث مهام VS Code للفحص والتشغيل والحالة.

GOV-00-01: المرجع والمصدر والأصول وملف القفل وصور المقارنة لم تتغير. GOV-00-02: استُخدم المستودع والفرع القائمان دون إعادة تهيئة أو push. GOV-00-06: آلية إغلاق المرحلة المنفصلة السابقة بقيت مع اختبارات الرجوع، وهي لم تُثبت على دمج بعيد بعد. GOV-00-04/05/07/08 لا تُستكمل من نجاح الاختبارات المحلية وحده.

## التحقق

اختبارات الحوكمة تشمل نقل JSON الأصلي، رفض تغيير المصدر والحالة والتقارير أثناء المراجعة، رفض تكرار العدّاد وتجاوز الجولة الرابعة، استئناف الاستيراد دون طلب جديد، رفض الفحوص الناقصة، القفل، المهلة، فشل executable، وحدود الصلاحيات وتوافق النسخ. البيانات الصناعية في الاختبارات معزولة عن سجلات المشروع.

اختبار نقل حي محدود نجح في attempts/coordinator-smoke-02: Claude CLI 2.1.263 أعاد نتيجة فعلية، ثم استلمها Codex CLI وأعاد إيصالًا بمعرّف جلسة Claude نفسه؛ خرج الطرفان برمز 0. هذا اختبار اتصال فقط، دون مراجعة مصدر أو تعديل أو احتساب جولة. المحاولة الأولى كشفت نسخة PATH أقدم 2.1.91 لا تدعم safe-mode؛ حُفظ الخطأ وأضيف فحص توافق مسبق بدل إزالة الحماية.

المحاولة coordinator-quality-01 اجتازت أوامر الفحوص التسعة لكن أداة quality رفضت اعتمادها بسبب تغير المصدر أثناء التشغيل؛ بقيت كاملة في attempts ولم يُحضّر عليها طلب مراجعة. الفحوص الكاملة أُعيدت على المصدر النهائي؛ دليل هذه الجولة هو tests.json وlogs الحاليان فقط، وتُضاف النتيجة المؤكدة أدناه قبل التسليم.

## العوائق وحدود العمل

عائق GitHub 403 الخاص بالحماية ما زال مسجلًا دون دليل حل جديد؛ لا PR أو CI بعيد أو merge لهذه المرحلة. لا شراء خطة أو تغيير خصوصية أو تجاوز حماية. فحص gate يثبت اتساقًا محليًا ولا يجيز الدمج بذاته. لم يبدأ Backend أو المرحلة 01.

المنسّق يطلق جلسات CLI مستقلة؛ لا يتحكم في نوافذ الإضافات أو يعيد إرسال الرسائل إلى هذه المحادثة. اختبار النقل لا يثبت نجاح إصلاح آلي للمصدر على هذا الجهاز؛ أي فشل sandbox أو إذن في التشغيل الفعلي يوقفه ولا يزيل العزل. إعادة المحاولة بعد خطأ جودة تتطلب حفظ المحاولة قبل إعادة كتابة جولة لم تُقدّم.

التراجع متاح من commits فرع المرحلة؛ لا أثر إنتاجي. يُطلب من Claude قراءة المصدر الفعلي والفروق وتقارير الأمان والاختبارات، وفحص الاستئناف وحماية الجولات وحدود صلاحيات الطرفين. يجب الإبلاغ عن الأدلة البعيدة الناقصة كعائق، دون اختلاق اعتماد. يتوقف تحرير المصدر بمجرد إرسال الحزمة إلى Claude.
